# ADR-0008: 综述工作台复用核验期数据，零新增外呼

日期: 2026-10-24 · 状态: Accepted

## 决策

`--review-kit`（综述就绪三件套：综述表格/标注书目/即贴 GB/T）是核验结果
的**另一种交付物形态**，不是新的核验通路：被引数只复用核验期已取的数据
（S2 citation contexts → OpenAlex 检索自带 cited_by_count → 诚实「—」），
不为此多发一个请求；GB/T 内联表与 `--export gbt7714` 共用同一行构造器
（`_gbt7714_entry`），杜绝双实现漂移；判定语义原样透出，工作台永不升级判定。

## 背景

「查文献/文献综述」需求池的用户要的是综述就绪交付物（表格/书目/参考文献
表），不是核验工作底稿——这是 v4.5.0 文献发现与 v4.9.0 工作台的分界。
竞品清单普遍未核验；我方差异化恰在「每条带官方核验判定」，因此判定列
必须原样出现在交付物里，宁可用户看到 partial 也不能让 partial 观感上
变成 verified。

## 后果

- 大批量 discover+review-kit 的网络成本与纯 discover 完全相同
- GB/T 输出单点维护：改收录策略只改 `_gbt7714_entry` 一处
- 工作台文案对判定语义的任何弱化（如把 partial 写成"基本可靠"）都是
  违反本 ADR 的回归
