# Out of Scope — cite-holmes 的非目标档案

> 「决定不做的事」与「能做什么」同样值得写清楚。本篇是防 scope creep 的
> 公开承诺：以下事项**有意不做**，不是"还没做"。每条带理由——如果理由
> 失效，欢迎开 issue 重开讨论。

| 不做什么 | 为什么 |
|---|---|
| PDF/Word 文档直读 | 解析器是依赖与攻击面的放大器；`--check-document` 已支持纯文本/markdown 正文。请先手工提取引用条目。 |
| 万方号/维普号等中文库专属编号直验 | 无公开权威 API；实测平台页为 JS 渲染/反爬。中文文献请走 DOI（ISTIC 前缀经桥接核验）或标题+URL 间接通道。 |
| 判定"网页所述事实本身的对错" | 机械层只验来源存在与一致性；"句子是否真被支撑"归语义层（`semantic` 字段）与人工。工具不说谎的方式之一是不越界。 |
| 自动求星/自动化平台互动 | 平台红线，且产品增长靠质量与口碑。报告页脚的 Star 链接只面向人类读者。 |
| 同模型自评 `semantic` 字段 | 自己审自己等于没审（反模式 #1）。语义判定请换独立模型或独立会话。 |
| 单批无上限（MCP） | 50 条/批是保护机制：防超长响应与限流雪崩。CLI 无此限（`--workers` 控并发）。 |
| 把 unreachable 判成 invalid | 抓取失败 ≠ 查无此物。只有注册库确凿回 404/标题不符才判死（ADR-0002/0005）。 |
| 未经论证的"信号改判定" | 启发式/统计/外部模型信号一律注记级（ADR-0005）；改判定必须另立 ADR。 |
| 反向合并 GitHub 改动进 trunk | 单向镜像保发布一致性（ADR-0006）；外部修复一律落 trunk。 |
